## 🤨 Wait, what is this?

There are roughly one million tutorials that teach you to build a todo app. This is not one of them. 🙅

The Chaos Button is a single-page interactive experience built around exactly one UI element: a large, suspiciously friendly button. Pressing it accomplishes nothing, and the button is honest about that. What it does instead is **escalate**. 📈

The first five clicks are innocent: a soft purple glow, a polite blip, a mildly philosophical remark. 🟣 By click ten the button has cracks, opinions, and trust issues. 💔 By click twenty your layout has gravity problems. 🍂 At click twenty-six it surrenders entirely and throws a golden enlightenment ceremony, complete with an orchestral swell synthesized from raw oscillators and a thank-you card for your pointless dedication. ✨ Then it forgets everything and starts over. Legally, nothing happened. Your localStorage disagrees. 🧾

This project exists because a button is the smallest possible unit of interactivity, and therefore the funniest place to spend an unreasonable amount of engineering. 🔧😅

## 🎭 The four phases

The engine counts your clicks and moves through four narrative phases. Each phase re-skins the page, swaps the sound palette, and unlocks new misbehavior. The button itself remembers nothing. Legally. ⚖️

| Phase | Clicks | Button label | Mood | What you see |
| :---- | :----- | :----------- | :--- | :----------- |
| 1️⃣ Innocent Testing | 1–5 | Press Me | 😇 Politely curious | Pristine purple glass button, slow breathing glow, mild weirdness |
| 2️⃣ Active Resistance | 6–15 | Stop That | 😑 Passive-aggressive | Cracks appear, colors desaturate, the button starts dodging and denying things |
| 3️⃣ Total Chaos | 16–25 | WHY | 🤬 Unhinged | Red vignette, glitching label, strobe, gravity stops working |
| 4️⃣ Enlightenment | 26 | Thank You | 🧘 Transcendent | Golden ceremony, four-chord orchestral swell, a thank-you card, then a full reset |

## ✨ Highlights

- 🎊 **29 behaviors**, picked 1–3 per press. Confetti cannons, alien abduction 🛸 (with performance review), a hypnosis spiral, a bureaucratic permit form with a 50/50 approval rate, a therapist mode that asks how pressing made you feel 🛋️, fake loading that stalls at 99% having loaded nothing, a button that runs away when you try to press it 🏃, and one that gets shy and hides. 🫣
- 📜 **42 embedded quotes** (obviously 42), from Socrates to Your Conscience.
- 🏆 **The Hall of Records**: 33 lifetime statistics and 46 unlockable records, from *Control Freak* to *Timeline Thief*. Includes a Behavior Census with per-behavior dossiers 📁, threat ratings, suppress and mute switches, a Chaos Seismograph that draws your session as a mountain range ⛰️, and a Flight Recorder that logs your incidents like a black box with opinions. ✈️
- 💾 **Backup export / restore** and **Duel Links** ⚔️: compress your entire records ledger into one URL, send it to a friend with worse numbers, absorb their timeline. The better number always wins. This is the only fair system in the project.
- 🔊 **100% synthesized audio.** Every boing, pop, glitch, alarm, tractor-beam glissando and orchestral swell is generated live from oscillators and filtered noise. There are no audio files. There was never an audio file. 🎺
- ⚡ **The Overcharge.** Press and hold to charge a detonation, then release above 50% to regret it properly. 💥
- 👥 **The Double Tap.** Two presses within a quarter second fork the timeline. Ghost buttons are included. Explanations are not. 👻
- 🎨 **5 themes** (Midnight 🌌, Daylight ☀️, Sepia 📼, Sodium ⚠️, Auto 🌗) that every instrument respects, including the seismograph drum.
- 🎮 **The Konami code is accepted.** Legally, nothing is unlocked. Emotionally, everything is. 🕹️
- 🪜 Press ranks from *Bystander* to *Legend of the Lab*. Yes, there is a ladder. No, it leads nowhere. That is the point.

## 🚀 Quick start ---˅  <img width="262" height="40" alt="Screenshot 2026-09-08 at 21 25 23" src="https://github.com/user-attachments/assets/cc03d2b5-23a5-447a-a68c-b23381cec5ea" />

```bash
# clone your fork (or the repo, we do not judge 🙃)
git clone https://github.com/blankcode-alt/the-chaos-button.git
cd the-chaos-button

# install (bun) — or use npm/pnpm, it is a standard Next.js app
bun install

# run the laboratory 🧪
bun run dev
```

Open `http://localhost:3000`. Press the button. 🔴 Keep pressing. Press it 26 times. Then press it 42 times, for reasons the page will explain with a straight face. 😐

> 💡 Requires no API keys, no database, no accounts, no cloud, no mercy. Everything runs client-side and persists in `localStorage`.

## 📂 Project structure

```
src/
├── app/
│   ├── layout.tsx        # metadata, fonts, the usual paperwork 📋
│   ├── page.tsx          # the stage: one page, one button, no routing
│   ├── icon.svg          # favicon, also a button, also useless
│   ├── chaos.css         # every theme, phase skin and animation
│   └── globals.css       # tailwind entry
├── lib/chaos/
│   ├── engine.ts         # the conductor 🎩: phases, behavior scheduling, easter eggs
│   ├── effects.ts        # stagecraft: shake, strobe, rotation, gravity incidents
│   ├── audio.ts          # the synthesized orchestra 🎻
│   ├── confetti.ts       # the confetti physics department 🎊
│   ├── quotes.ts         # 42 aphorisms and their long-suffering authors 🧑‍🏫
│   ├── achievements.ts   # the Hall of Records: stats, records, census, backups 🏆
│   ├── seismo.ts         # the Chaos Seismograph ⛰️
│   └── settings.ts       # the Control Room: themes, dials, persistence 🎛️
├── components/ui/        # the handful of shadcn/ui primitives actually used
└── hooks/
    └── use-toast.ts      # toast plumbing
```

Built with Next.js 16, TypeScript, Tailwind CSS 4, a Canvas element, the Web Audio API and a plain CSS file. No animation libraries. No confetti packages. No webfonts you did not agree to. 🧼

## 🤝 Contributing

Contributions are welcome. This is an open laboratory for high-effort uselessness, and the bar for entry is simple: **does it make the button better at being a button?** 🧪

Good ideas that got merged before you arrived: gravity incidents, alien abduction, a permit form, an entire seismograph. The bar is on the floor and people still managed to limbo under it. 🕺 You can do better. 💪

1. 🍴 Fork the repository
2. 🌿 Create a branch: `git checkout -b feat/my-feature` (or `fix/`, or `chaos/`, we are not strict about prefixes, only about fun)
3. ✏️ Make your change. Keep the copy deadpan. The humor is in the restraint.
4. ✅ Run `bun run lint` and `bun run typecheck` so CI does not write a passive-aggressive comment about you
5. 📬 Open a Pull Request and describe what your button does

💡 Ideas currently accepting applications:

- 🪧 A behavior where the button unionizes
- 🏆 More records (the Hall of Records has room; it is very spacious for a panel)
- ⛰️ A seismograph replay easter egg nobody asked for
- 🌍 Translations of the gaslighting into additional languages, one of which is Morse code, one of which is not
- 🤷 Whatever you can think of that a reasonable product manager would reject
